# لوحة إدارة منصة الهندسة الزراعية (`admin/`)

جزء من المنصة نفسها: تفتح من `admin/index.html` (أو من زر «🛡️ لوحة الإدارة» في الهيدر للمسؤول).
تستخدم **نفس تسجيل الدخول ونفس قاعدة البيانات ونفس شكل المنصة** (الهيدر والفوتر والثيم الليلي/النهاري).

## الإعداد (مرة واحدة)
1. `js/config.js` (في جذر المشروع): الصق **Publishable Key** الخاص بمشروع Supabase في `SUPABASE_KEY`
   (Supabase → Project Settings → API Keys). هذا الملف الوحيد الذي يقرأ منه الموقع واللوحة.
2. نفّذ `database/admin/001_admin_setup.sql` ثم `002_add_admin.sql` (بعد وضع بريدك فيه) — انظر `database/admin/README.md`.
3. سجّل حسابك من `login.html` وأكّد بريدك، ثم افتح لوحة الإدارة.

## كيف تعمل
| الجزء | الملفات |
|---|---|
| الدخول | دخول المنصة الأصلي (`login.html` + `js/auth.js`). بلا جلسة تحوّلك اللوحة إلى صفحة الدخول ثم تعيدك إليها |
| من هو المسؤول؟ | الدالة `is_admin()` في PostgreSQL (بريد في `admin_emails` + حساب مؤكَّد) — `js/core/access.js` |
| الإقلاع والهيكل | `js/core/app.js` (جلسة ← مسؤول؟ ← القائمة الجانبية ← الراوتر) |
| الراوتر والوحدات | `js/core/router.js` (hash `#/وحدة` + تحميل كسول) و`js/modules/registry.js` (قائمة الوحدات) |
| البيانات | `js/core/data.js` — الوحيد الذي يكلّم Supabase (Repository: قائمة/بحث/ترقيم/إضافة/تعديل/حذف) |
| صفحة إدارة جدول | `js/core/crud.js` — تُبنى من وصف بسيط؛ كل وحدة ملف صغير في `js/modules/` |
| الأمان | `js/core/dom.js` — قالب `html\`...\`` يهرّب كل نص قادم من قاعدة البيانات تلقائيًا |

## الوحدات
المواد الدراسية · ملفات المواد · أقسام «المزيد» · محتوى الأقسام · المصادر الخارجية · الأوائل · جداول الامتحانات ·
هيئة التدريس · مجتمع الطلاب والخريجين · الغرف · المهام ومحتواها (محرر عناصر) · أسئلة المهام · المسؤولون (عرض).

## إضافة وحدة جديدة
1. ملف في `js/modules/` يستدعي `AdminCrud.define('id', {...})` (انظر `subjects.js` كمثال).
2. سطر في `js/modules/registry.js` بنفس الـ id.

## قواعد
- إخفاء الأزرار ليس حماية؛ الحماية في RLS (`admin_all`). لا تضع مفتاح `service_role` في أي ملف.
- لا تستدعِ `supabase.createClient()`؛ العميل الوحيد من `PlatformAuth.getClient()`.
